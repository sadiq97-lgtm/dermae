# Dermaé 🌿

A premium skincare e-commerce experience built with React, Supabase, and Vercel.

## Live Demo

🔗 https://dermae-three.vercel.app

## Features

- Responsive Mobile-First Design
- Product Catalog
- Wishlist System
- Shopping Cart
- Smart Skin Advisor
- Admin Dashboard
- Product Management
- Dark / Light Mode
- Arabic & English Support

## Tech Stack

- React
- Vite
- Supabase
- Framer Motion
- CSS
- Vercel
